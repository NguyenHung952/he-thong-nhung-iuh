# 🤖 Hệ thống nhúng – IUH

Repository tổng hợp tài liệu, bài thực hành và ghi chú phục vụ môn **Hệ thống nhúng** tại IUH.

## 📚 Định hướng nội dung

- Kiến trúc và nguyên lý hệ thống nhúng.
- Vi điều khiển, giao tiếp ngoại vi và cảm biến.
- Lập trình, kiểm thử và triển khai hệ thống.
- Tài liệu thực hành và các bài tập theo tuần/chủ đề.

## 🗂️ Cấu trúc đề xuất

```text
he-thong-nhung-iuh/
├── README.md
├── ly-thuyet/
├── thuc-hanh/
├── bai-tap/
├── code/
└── tai-lieu-tham-khao/
```

## 🎯 Mục đích

- Tổ chức tài liệu và mã nguồn theo từng nội dung học.
- Dễ theo dõi tiến độ thực hành.
- Thuận tiện bổ sung sơ đồ mạch, ảnh kết quả và hướng dẫn chạy.

## 📝 Quy ước đề xuất

- Đặt tên thư mục bằng chữ thường, dùng dấu gạch ngang.
- Mỗi bài thực hành nên có README riêng nếu có nhiều bước thực hiện.
- Không đưa mật khẩu, API key hoặc thông tin cá nhân vào repository.
